# Painel de Usuários

Projeto simples em Next.js (pasta `pages`) com lista e detalhes de usuários mockados.

## Como rodar

```
npm install
npm run dev
```

Depois abra http://localhost:3000

## Rotas

- `/` — Home
- `/usuarios` — lista de usuários
- `/usuarios/[id]` — detalhes do usuário
- `/sobre` — sobre o projeto
